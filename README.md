# Родительский контроль (Android, Kotlin)

Простое открытое приложение для контроля экранного времени ребёнка.

## Возможности
- PIN родителя (хранится как SHA-256 с солью) для входа в настройки
- Блокировка выбранных приложений
- Дневной лимит времени (минуты) для любого приложения
- Экран блокировки с кнопкой «На главный экран» и временной разблокировкой по PIN (15 мин)
- Постоянное уведомление: ребёнок видит, что контроль активен (скрытого режима нет — намеренно)
- Автозапуск после перезагрузки

## Сборка
1. Откройте папку в Android Studio (Koala или новее), дождитесь Gradle Sync
   (Android Studio сама подтянет Gradle 8.7 и SDK 34).
2. Build → Build APK(s). Файл: `app/build/outputs/apk/debug/app-debug.apk`.
   Из консоли (если есть gradle): `gradle assembleDebug`.

## Первый запуск на устройстве ребёнка
1. Задайте PIN.
2. Выдайте «Доступ к статистике использования» и «Показ поверх других окон».
3. Включите переключатель «Контроль включён».
4. На некоторых оболочках (Xiaomi, Huawei, Samsung) отключите оптимизацию батареи
   для приложения и разрешите автозапуск, иначе система может остановить сервис.

## Ограничения и идеи развития
- Ребёнок может удалить приложение. Защита: Device Admin / Android Enterprise (Device Owner)
  или Google Family Link.
- Не блокирует системные настройки и браузерный контент — для этого добавьте
  AccessibilityService или DNS-фильтрацию.
- Для удалённого управления с телефона родителя понадобится бэкенд (например, Firebase).

Используйте только на устройствах своих детей и с их ведома.
